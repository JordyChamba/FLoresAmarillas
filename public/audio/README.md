# Música

Coloca aquí tu archivo como `music.mp3`:

```
public/audio/music.mp3
```

- Formato recomendado: MP3, ~128–192 kbps, 2–4 min en loop.
- La app lo reproduce con `new Audio('/audio/music.mp3')` en loop.
- Nunca hay autoplay: el visitante pulsa el botón 🔊.
- Si el archivo falta, el botón muestra este aviso sin romper nada.
